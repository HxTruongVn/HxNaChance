# Milestones

## M0 — Documentation / Architecture Truth
`CURRENT`

Mục tiêu:

- docs phản ánh code thật;
- tách current architecture khỏi vision;
- xác định rõ PARTIAL/PLANNED;
- không kéo chi tiết Workshop vào Core docs.

## M1 — Core Resource Contract

Mục tiêu:

```text
Declare → Resolve → Provision → Verify
```

với schema thống nhất.

## M2 — Core Lifecycle

Mục tiêu:

- Workshop status;
- resource state;
- bootstrap progress;
- integration tests.

## M3 — Pipeline Core

Mục tiêu:

- validation;
- execution orchestration;
- stable Workshop interface.

## M4 — Packaging / Distribution

Sau khi Core ổn định:

- Windows packaging;
- installer;
- offline/online resource policy;
- version/update.

> Các mốc trên không phải cam kết release date.
> Chúng là thứ tự phụ thuộc kỹ thuật.
